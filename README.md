# 🤝 HandshakeDealBot

Telegram-бот для безопасных P2P-сделок с **эскроу-гарантом**. Покупка и продажа товаров и услуг между пользователями — все транзакции через **USDT (TRC-20)**, деньги заморожены на эскроу до завершения сделки.

## 🔐 Главный принцип — безопасность

**Бот выступает как смарт-контракт:** деньги покупателя замораживаются на кошельке бота и отправляются продавцу **только после подтверждения получения товара/услуги**. Никто не может обмануть — средства защищены.

## 📋 Возможности

- **Эскроу-гарант** — деньги на кошельке бота до завершения сделки
- **Автоматический поток** — без участия админа при стандартных сделках
- **Авто-завершение** — через 72ч после доставки если нет спора
- **Система споров** — средства заморожены до решения администратора
- **Каталог объявлений** — товары и услуги с категориями
- **Рейтинг и отзывы** — 1-5 звёзд после каждой сделки
- **Админ-панель** — статистика, баны, споры, мониторинг эскроу

## 🔄 Как работает сделка (автоматический поток)

```
Покупатель                    Бот (Эскроу)                  Продавец
    │                              │                              │
    │── Начать сделку ────────────>│                              │
    │                              │── Уведомление ──────────────>│
    │── USDT → кошелёк бота ─────>│                              │
    │── Указал TxID ─────────────>│ 🔐 Средства заморожены       │
    │                              │── Деньги на эскроу! ────────>│
    │                              │                              │
    │                              │<── Заказ выполнен ───────────│
    │<── Заказ доставлен! ─────────│                              │
    │                              │                              │
    │── ✅ Подтверждаю получение──>│                              │
    │                              │── 💵 Выплата продавцу ──────>│
    │                              │                              │
    │── ⭐ Отзыв ─────────────────>│<── ⭐ Отзыв ─────────────────│
```

### Защита от мошенничества:
- **Продавец не получит деньги**, пока покупатель не подтвердит получение
- **Покупатель не потеряет деньги** — при споре средства заморожены
- **Авто-таймер 72ч** — если покупатель молчит и не спорит, сделка завершается
- **Админ решает споры** — при конфликте обе стороны защищены

## 🚀 Установка и запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка
Скопируйте `.env.example` → `.env` и заполните:

```env
BOT_TOKEN=123456:ABC-DEF...       # Токен от @BotFather
ADMIN_ID=123456789                 # Ваш Telegram ID
BOT_COMMISSION=2                   # Комиссия в % (2 = 2%)
BOT_WALLET=T...                    # TRC-20 кошелёк для эскроу
AUTO_COMPLETE_HOURS=72             # Авто-завершение (часы)
```

### 3. Запуск
```bash
python bot.py
```

## 🤖 Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Регистрация и главное меню |
| `/help` | Справка по эскроу и использованию |
| `/wallet T...` | Установить USDT-кошелёк (TRC-20) |
| `/admin` | Админ-панель (только для админа) |
| `/ban ID` | Заблокировать пользователя |
| `/unban ID` | Разблокировать пользователя |
| `/resolve ID seller` | Спор — выплатить продавцу |
| `/resolve ID buyer` | Спор — вернуть покупателю |

## ⚠️ Важно

- Бот выступает **эскроу-гарантом** — все деньги проходят через кошелёк бота
- Продавец получает выплату **только после подтверждения** покупателем
- При споре — средства **заморожены** до решения администратора
- Авто-завершение через 72ч защищает продавца от молчания покупателя
- Сеть **TRC-20** (TRON) для USDT
